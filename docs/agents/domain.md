# Domain documentation

This is a single-context repository. The initial domain boundary is the GGK
3.0.2 formal baseline under `formal/ggk-v3.0.2/`.

Use the vocabulary already established by the formal model and its result
record. When a term is missing or overloaded, record the decision in a domain
specification before changing model names. When a new architectural decision
is durable, record it under `docs/adr/`.

Do not silently widen a bounded formal result into a universal claim.
